Política de Privacidade — Cortes GTA 6 BR Poster

Última atualização: 19 de novembro de 2026

1. Dados que usamos

Ao autorizar a ferramenta, o TikTok nos fornece um token de acesso e as informações básicas do perfil (identificador aberto, nome de exibição e foto). Usamos isso apenas para enviar vídeos para a conta que autorizou.

2. Onde ficam

O token fica salvo somente no computador do dono do canal, que roda a ferramenta localmente. Não temos servidores, banco de dados de usuários nem compartilhamos dados com terceiros.

3. Outros usuários

A ferramenta não coleta dados de outros usuários do TikTok. Ela não lê comentários, mensagens, seguidores nem vídeos de terceiros.

4. Exclusão

Para apagar os dados, basta revogar o acesso no aplicativo TikTok (Configurações e privacidade → Segurança → Apps e serviços). O token salvo deixa de funcionar imediatamente.

5. Contato

Pelo canal: Cortes GTA 6 BR no YouTube.

Privacy Policy — Cortes GTA 6 BR Poster

Last updated: November 19, 2026

1. Data we use

When the tool is authorized, TikTok provides an access token and basic profile information (open ID, display name and avatar). We use it only to upload videos to the account that authorized it.

2. Where it is stored

The token is stored only on the channel owner's computer, which runs the tool locally. We have no servers, no user database, and we do not share data with third parties.

3. Other users

The tool does not collect data from any other TikTok users. It does not read comments, messages, followers or other people's videos.

4. Deletion

To delete the data, revoke access in the TikTok app (Settings and privacy → Security → Apps and services). The stored token stops working immediately.

5. Contact

Through the channel: Cortes GTA 6 BR on YouTube.
